# 🧾 Ads.txt Monitoring Template

[![Latest Release](https://img.shields.io/github/v/release/Ilana-Bonas/spot.im?label=release)](https://github.com/Ilana-Bonas/spot.im/releases)
[![Use this template](https://img.shields.io/badge/GitHub-Use%20this%20template-brightgreen?logo=github)](https://github.com/Ilana-Bonas/spot.im/generate)

Monitor and alert on changes in ads.txt lines across publisher domains using Google Sheets and Apps Script — no AWS required.

---

## 📦 What's Inside

- ✅ Excel tracker with conditional formatting
- 🧠 Google Apps Script: `checkNewLines()` + `sendAlertEmail()`
- 📘 Setup guide for Sheets + Time-based triggers
- 🧰 Ready-to-use GitHub template

---

## 🚀 How to Use

1. Click **“Use this template”** above to create your own repo
2. Upload the Excel and script files from the setup guide
3. Paste the Apps Script into your Google Sheet
4. Set daily triggers for automated checks and alerts

---

## 🛠 Stack

- Google Sheets (daily status log + visual flags)
- Gmail (automatic alerts)
- Google Apps Script (logic + timing)
- No AWS or backend required
